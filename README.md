# 🧭 Полюс-14 — математическая экспедиция

Тренажёр по математике для 6 класса: школьная программа (масштаб, доли, проценты, отрицательные числа, геометрия) плюс олимпиадные «десерты». Ребёнок ведёт экспедицию к полюсу: решает задачи, набирает монеты, открывает ящики с настоящими призами от родителей и проходит развилки, где у каждого решения есть последствия.

**Все задачи — авторские.** Ни одна не скопирована из чужих сборников или листков кружков: тексты, сюжеты, числа и персонажи написаны с нуля для этой экспедиции. Идеи (масштаб, доли, проценты) — общеизвестный школьный канон и не охраняются авторским правом; охраняется текст, и он здесь наш.

## Как открыть без интернета

Двойной клик по `index.html` — сайт откроется в браузере. Рабочие файлы (не переименовывать): `index.html`, `style.css`, `app.js`, `data.js`.

Прогресс (монеты, решённые задачи, призы) хранится в браузере на том устройстве, где занимаются. На странице «Профиль» есть кнопка «Сохранить прогресс в файл», на странице «Родителям» — загрузка сохранения.

## Родителям

1. Внизу страницы нажмите **🔑 Родителям**.
2. Придумайте PIN из 4 цифр (при первом входе — дважды).
3. Впишите, что лежит в ящиках (они открываются на 200, 450, 750, 1100, 1500, 2000, 2600, 3300, 4100, 5000 монет). Ориентир: первое занятие — примерно 200–450 монет.
4. Нажмите «Сохранить призы». Тексты призов остаются только в браузере ребёнка.

Там же — «Записи полярника» (черновики решений из «бумажных» задач) и отчёт за неделю. Слово-шифровку родители видят в разделе «Полезно знать» — подсказывать не нужно, за разгадку положен главный приз.

## Аккаунты, семья и PIN

- Аккаунт один на семью: почта (логин) и пароль. Внутри аккаунта — профили детей: имя, класс и прогресс.
- Ребёнок играет под своим профилем; прогресс синхронизируется с аккаунтом и доступен на другом устройстве.
- Родительский режим (статистика, записи, призы) открывается PIN из 4 цифр. PIN хранится в аккаунте, работает на любом устройстве.
- Забыли PIN: на странице «Родителям» — восстановление по паролю аккаунта и коду восстановления, который выдаётся при регистрации.
- Первый этап каждого класса бесплатный; остальные открываются кодом доступа, купленным на класс.
- Платные этапы не хранятся в этом репозитории: сервер отдаёт их только после проверки права.

## Что внутри

- **Этап 1 «Старая карта»** — масштаб, доли пути и припасов, 12 задач + перевал «Треугольное озеро» (бесплатно).
- **Этап 2 «Доли и дроби»** — провизия и порции, 12 задач + перевал «Полярный обед».
- **Этап 3 «Проценты на льду»** — топливо, скидки, изменения цен, 12 задач + перевал «Двойное подорожание».
- **Этап 4 «Отрицательные широты»** — температура, координаты, модуль, действия с минусами, 12 задач + перевал «Ночь на термометре».
- **Этап 5 «Ледяная геометрия»** — периметр, площадь, объём, 12 задач + перевал «Тёплые стены».
- **Этап 6 «Полюс»** — финал: чётность, делимость, комбинаторика, среднее; 12 задач + финальная загадка «три ящика».
- **Развилки на маршруте** — сюжетные выборы между этапами.
- **Штурм-контрольная** — 8 авторских задач, 90 минут.
- **Шифровка «АЗИМУТ»** — шесть букв за пять перевалов и контрольную.
- Задача дня, звания, 8 наград, три темы оформления, блокнот для черновиков, телеметрия для родителей.
- **Личный кабинет** («📊 Кабинет»): для ребёнка — маршрут, неделя по дням, темы, рекорды и «что дальше»; для родителей (по PIN) — время занятий, самостоятельность, темы с рекомендациями, где застревал, записи рассуждений и печать отчёта.

Все 60 задач этапов, 5 перевалов, 8 задач контрольной и задачи дня — авторские, написаны для «Полюса-6» с нуля.

## Как выложить в интернет

Сайт — статический: GitHub Pages, любой хостинг или просто папка на диске. Для GitHub Pages: репозиторий → Settings → Pages → Branch `main`, папка `/ (root)`.

После правок `app.js`/`data.js`/`style.css` обязательно поднимайте `?v=N` в `index.html`, иначе браузер покажет старую версию из кэша.

## Платные этапы: как обновлять

Этапы 2–6 лежат не в репозитории, а в хранилище Cloudflare (KV) и загружаются скриптом `_sovenok/upload_pole6_stages.py` из файла `_sovenok/pole6_premium.json`. Коды доступа выдаются админ-скриптом (см. PLAYBOOK, раздел 7а).
